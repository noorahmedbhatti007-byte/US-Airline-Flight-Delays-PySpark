## Analysis and Prediction of U.S. Airline Flight Delays Using PySpark

## Project Objective

This project will conduct a large-scale analysis of U.S. domestic airline flight delays using PySpark. The study will investigate how flight-delay patterns vary according to temporal and operational characteristics such as airline, origin and destination airports, route, month, day of the week, scheduled departure period, and flight distance.

Descriptive analysis will also examine reported delay categories, including air-carrier, weather, National Aviation System (NAS), security, and late-aircraft delays.
